# Checklist de soumission X-IA

## Obligatoire

- [ ] vidéo de deux minutes maximum relue avec le son ;
- [ ] description courte du projet ;
- [ ] URL de ce dépôt et instructions de test vérifiées ;
- [ ] noms des membres de l'équipe ;
- [ ] dépôt effectué avant le 27 septembre 2026 à 23 h 59 ;
- [ ] reçu de soumission conservé.

## Contrôle technique

- [ ] `./scripts/run_winner_demo.sh` termine avec 13/13 contrôles ;
- [ ] les cinq empreintes sémantiques sont identiques ;
- [ ] chaque constat montré possède une preuve ;
- [ ] aucune décision bloquante n'est publiée automatiquement ;
- [ ] aucune clé, aucun fichier `.env` et aucune donnée client réelle ne sont
  présents dans le dépôt.

## Déclaration d'antériorité

- [ ] préciser que la vision The Flow Fabric et Flow Atlas préexistaient ;
- [ ] identifier clairement les composants Flow Scout réalisés pendant le
  hackathon, conformément à la section dédiée du README.

Une URL publique peut renforcer l'expérience utilisateur, mais elle ne fait pas
partie des quatre livrables obligatoires énumérés dans le règlement officiel.
